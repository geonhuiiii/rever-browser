rever-browser iframe fixture

Measures what the snapshot can currently see inside frames. Each child holds K1 (button), K2 (link), K3 (pointer div).

CONTROL. Main-document button

Must always get a ref. If this is missing, the page failed to load, not the frame logic.

H. Same-origin iframe (127.0.0.1:8777)

Same origin, same process. Expect K1, K2, K3 refs if frame content is reachable at all.

I. Cross-origin, same site (127.0.0.1:8778)

Different port, so cross-origin for JS, but Chrome sites ignore port - likely the SAME renderer process.

J. Cross-site iframe (localhost:8778)

Different host, so a different site - this is the one likely to become an out-of-process iframe (OOPIF), which needs a separate CDP session to reach.

Report per group: how many of K1/K2/K3 appear, and whether any carries a [ref].
