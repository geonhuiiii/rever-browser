rever API reversing target

Every answer a tool should produce is printed next to the control that produces it.

A. Auth

POST /api/v3/login returns an HS256 JWT with sub=u_42, role=admin, and stores it in localStorage["auth.token"] plus an HttpOnly session cookie.

B. Signed API calls

Both send x-signature = HMAC-SHA256 over METHOD\nPATH\nBODY\nTIMESTAMP with key s3cr3t-signing-key. Replaying either without re-signing must return 403 bad_signature — that is the check a replay tool has to survive.

C. WebSocket

Server greets with {"type":"hello"} and echoes anything sent.

D. Injection surfaces

/api/v3/echo reflects name into the x-echo response header. /api/v3/file?p= serves files by relative path. /api/v3/admin/keys exists but is referenced by no page code — only guessing finds it.
