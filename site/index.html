See every request. Ask what it means. Reproduce it.

rever-browser puts a reverse-engineering agent next to a real Chromium tab. You browse the target; the app records every request over CDP, and the agent reads that traffic, cracks open the JavaScript bundles, and drives the tab itself.

01

Live traffic capture

Every Network.* event from the tab lands in a ring buffer. Response bodies are fetched lazily on loadingFinished, and image, video, font and CSS payloads are skipped so the buffer stays readable.

Local by construction

03 architecture

Three processes, one strict boundary.

Node APIs and the CDP debugger never leak into the page. Everything crosses through preload IPC, the single source of truth for the renderer-visible surface.

main

Owns Chromium and the agent

The only process with Node and Electron APIs.

  • webContents.debugger (CDP)
  • traffic-store ring buffer
  • spawns the ACP child process
  • hosts the HTTP MCP server
preload

The only door between them

Exposes window.rev through contextBridge.

  • typed RevAPI surface
  • per-prompt update channels
  • no Node reaches the page
renderer

What you actually touch

React 19 and Vite: the tab, the traffic list, the chat.

  • <webview> host
  • live traffic list
  • streaming chat panel
capture  ·  Network.* → traffic-store → network-event IPC → TrafficList
agent  ·  prompt → ACP session → MCP tool → CDP → streamed answer
04 tool surface

134 tools, grouped by what you are trying to learn.

05 quickstart

Running in about a minute.

Bun is the package manager, not npm or pnpm. The agent binary installs separately because it runs as its own process.

zsh
# 1 — the agent binary, on your PATH
$ npm i -g @agentclientprotocol/claude-agent-acp

# 2 — the app
$ git clone https://github.com/greekr4/rever-browser
$ cd rever-browser
$ bun install
$ bun run dev

# optional — unminify captured bundles
$ npm i -g webcrack

before you point it somewhere

rever-browser drives a real browser against real servers. Use it on your own services, on systems you have written permission to test, or on targets that invite it, and follow the site's terms and your local law.

It is a debugging tool for people who already have the right to look.

Read the capture. Then read the code.
